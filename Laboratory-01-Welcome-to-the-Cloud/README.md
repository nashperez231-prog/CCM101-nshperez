# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory introduced me to the Linux environment and the basic responsibilities of a cloud infrastructure engineer. I used the KillerCoda Playground to practice Linux commands and prepared a GitHub repository for my cloud computing portfolio.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore the Linux file system.
- Gather basic system information.
- Create and organize files and directories.
- Practice using Git and GitHub.
- Document technical activities using Markdown.

## Activities Performed

1. Accessed an Ubuntu Linux environment through KillerCoda.
2. Created and configured a new Linux user.
3. Logged in to the new user account.
4. Checked the username, working directory, and hostname.
5. Gathered system information.
6. Created directories and Markdown files.
7. Created and organized a GitHub portfolio repository.

## Linux Commands Used

- `whoami` - Shows the current username.
- `pwd` - Shows the current working directory.
- `hostname` - Shows the system hostname.
- `uname -r` - Shows the kernel version.
- `lscpu` - Displays CPU information.
- `free -h` - Displays memory information.
- `df -h` - Displays disk space.
- `mkdir` - Creates directories.
- `cd` - Changes directories.
- `ls` - Lists files and directories.
- `nano` - Creates and edits files.
- `cat` - Displays file contents.
- `cp` - Copies files.
- `git clone` - Clones a GitHub repository.

## Skills Learned

I learned how to navigate and manage a Linux environment, collect basic system information, organize files, and create technical documentation. I also gained experience using Git and GitHub to maintain a cloud computing portfolio.
